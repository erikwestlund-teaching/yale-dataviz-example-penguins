# Module 2: Example Visualization — Palmer Penguins

A small instructor-led demonstration for AI-Augmented Analytics for Data Visualization.

1. Open `yale-dataviz-example-penguins.Rproj` in RStudio, or open this folder in Positron.
2. Run `source("setup.R")` in the R console.
3. Use the ask on the course page to complete `notebooks/penguins.qmd`.

The project contains one dataset, its codebook, and one blank notebook. It has no project skills. The raw CSV keeps the original missing values for the cleaning demonstration.

Data: [palmerpenguins](https://allisonhorst.github.io/palmerpenguins/). See `inputs/raw/codebooks/penguins.md` for variables and attribution.
